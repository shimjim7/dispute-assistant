# Dispute Assistant

A customer-facing card-dispute assistant for a bank, built end to end and shipped with its own governance pack. Synthetic data only.

## Status
Week 1 of 12. Work in progress.

## Goals
- Development: a tested, containerized tool-calling agent deployed on free infrastructure
- Business: discovery brief, KPIs, ROI model, pilot plan
- Governance: risk tiering, guardrails, monitoring plan, runbook, model card
